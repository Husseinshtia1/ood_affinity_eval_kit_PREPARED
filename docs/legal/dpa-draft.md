# PREPARED.ai Data Processing Agreement (DPA) — Draft

Last updated: 2026-05-23

> Draft only. Requires legal review.

## Scope

This DPA describes processing responsibilities between PREPARED.ai and customers.

## Processing categories

- User account data
- Organization metadata
- Evaluation artifacts
- Logs and audit records

## Responsibilities

PREPARED.ai:
- Applies reasonable technical controls.
- Limits internal access.

Customer:
- Ensures lawful data submission.
- Obtains required permissions.

## Subprocessors

Subprocessors should be documented before production use.
